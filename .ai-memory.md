# PROJECT MEMORY — aisanity

## Identity
- Project: aisanity (AI Memory Guardian)
- Purpose: Catch AI context drift and hallucination by validating AI suggestions against documented project constraints
- Language: Python 3 (stdlib only — no external dependencies)

## Environment
- OS: Linux
- Python interpreter: python3
- Package manager: pip
- No virtual environment required for this project

## Architecture
- `guardian.py` — main entry point, CLI + library
- `.ai-memory.md` — this file; plain-text project memory, used as LLM system prompt
- Primary LLM backend: Ollama server at 192.168.86.45:11434
- Fallback LLM backend: GitHub Models API (free tier via Copilot subscription)

## Critical Requirements
### LLM Backend
- REQUIRED: Local Ollama server at 192.168.86.45:11434 as primary
- FALLBACK: GitHub Models API at models.github.ai when Ollama is unreachable
- NEVER use paid API services or hardcoded API keys in source code

### Dependencies
- REQUIRED: Python stdlib only (urllib, json, pathlib, argparse, sys, os, dataclasses)
- FORBIDDEN: requests, httpx, openai, or any external package
- Reason: Zero-dependency tool that works anywhere Python 3.7+ is installed

### Memory File Format
- REQUIRED: Plain-text Markdown (.ai-memory.md)
- FORBIDDEN: JSON config files for project memory
- Reason: Human-readable, LLM-native format that doubles as the system prompt

## Forbidden Patterns
- Never import external packages (requests, openai, etc.)
- Never hardcode API keys or tokens in source code
- Never use JSON for the project memory file
- Never skip the Ollama backend and go straight to GitHub Models
- Never use synchronous blocking calls without a timeout

## Common Mistakes
| Wrong | Correct | Why |
|-------|---------|-----|
| `import requests` | `import urllib.request` | Stdlib only, no external deps |
| `json config file` | `.ai-memory.md` markdown | Human-readable, LLM-native |
| `hardcoded API key` | `os.environ["GITHUB_TOKEN"]` | Security: tokens from env vars |
| `no timeout on HTTP` | `urllib.request.urlopen(req, timeout=10)` | Prevent hanging on unreachable server |
